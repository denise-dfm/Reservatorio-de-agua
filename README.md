# Reservatorio-de-agua
Sistema de monitoramento de um reservatório de água

💧 Controle de Níveis de Água
Sistema desenvolvido em Python para monitoramento de um reservatório de água via terminal.

📋 Descrição
O programa permite informar o nível atual do reservatório e exibe uma mensagem colorida correspondente à situação da água.

A aplicação utiliza a biblioteca Colorama para destacar visualmente cada nível de alerta.

🚦 Níveis do Reservatório
Nível	Situação	Cor
🔴 1	Muito baixo (crítico)	Vermelho
🟡 2	Baixo	Amarelo
🟢 3	Médio	Verde
🔵 4	Alto	Ciano
🔷 5	Muito alto (alerta)	Azul

⚙️ Funcionalidades
✅ Exibição de mensagens coloridas no terminal
✅ Uso de listas para armazenamento das situações
✅ Função para definir a cor de cada nível
✅ Validação da entrada do usuário
✅ Execução em loop até o encerramento pelo usuário
✅ Restauração automática das cores do terminal

📦 Tecnologias Utilizadas
🐍 Python 3
🎨 Colorama
🚀 Instalação

Biblioteca necessária:
pip install colorama
